# Figures

Twelve display items, each shipped as:

- `*.png` — raster preview at **300 dpi** (ragg), for quick viewing.
- `*.pdf` — **editable vector** output (R / Quartz), for publication.

The PDFs are the submission artifacts; open them in Adobe Illustrator /
Inkscape to edit text or layout. All figures are generated by
`../code/R/run_all.R` from `../data/source_data/`. No AI-generated artwork.
