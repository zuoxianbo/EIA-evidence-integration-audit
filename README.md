# EIA — Auditing Information Attribution in Biomedical Evidence Integration

**Reproducibility repository** for the Nature Methods submission
*"Auditing information attribution in biomedical evidence integration"*.

> All figures are generated with **R / ggplot2** (no AI-generated artwork).
> Every figure ships as both a 300 dpi PNG and an editable vector PDF.
> No numeric value in any figure or table is fabricated.

---

| Directory | Contents |

## The analysis pipeline (Python)

`code/python/run_analysis.py` is the **single source of truth** for every
reported number. It computes, under one frozen configuration:

- **19 scorers** — 9 single-layer evidence sources, 7 fixed-form composites,
  3 supervised integrators (random forest, logistic regression, elastic net);
- **paired bootstrap** — B = 2,000 replicates, seed `20260819`;
- **one-sided P values** — `P = (#{Δ ≤ 0} + 0.5) / (B + 1)`, right-tail
  (H1: Δ > 0). The minimum attainable value under this formula is
  `0.5 / 2,001 ≈ 0.00025`; this is a property of the estimator, **not** a
  resolution limit of the bootstrap;
- **95% confidence intervals** — 2.5th / 97.5th percentiles of the same
  paired-bootstrap Δ distribution;
- **multiplicity** — Benjamini–Hochberg across the prespecified 60-contrast
  inferential family (m = 60);
- **vectorised nulls** — N = 1,000 degree-decile shuffle controls.

Frozen audit conventions: sentinel value `−3`, harmonic-mean aggregation,
missingness treated as a cross-cutting benchmark condition, external drug
response (E6) reported separately from the 60-test family.

## The figure pipeline (R)

All 12 figures are regenerated by:

```bash
Rscript code/R/run_all.R
```

Each script is self-contained and sources `common.R`. Paths resolve relative to
the repository root, so the repository can live anywhere on disk.

---

## Reproducing the analysis

```bash
# 1. environment
conda env create -f environment.yml
conda activate eia-repro

# 2. frozen analysis (writes data/results/ and the ledger)
python code/python/run_analysis.py

# 3. post-process into publication tables
python code/python/postprocess.py

# 4. figures (12 PNG + 12 PDF)
Rscript code/R/run_all.R
```

### Third-party data that are NOT redistributed here

The GDSC / DeepCDR external drug-response files used for the E6 audit are
**not** redistributed in this repository, in accordance with the providers'
terms of use. Point the pipeline at your own copy with the `GDSC_DIR`
environment variable:

```bash
export GDSC_DIR=/path/to/DeepCDR/data
```

All other inputs are public resources referenced by immutable identifiers
(STRING v12, DepMap 23Q2, gnomAD, COSMIC, Open Targets Genetics, DGIdb/ChEMBL,
Human Protein Atlas). Gene-level harmonization is fully scripted and
reproducible from `data/raw_inputs/`.
